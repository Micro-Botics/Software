# Software

Para que se peude ejecutar código en esp hay que descargar 2 cosas. Esptool, adafruit-ampy. Para eso entrais en vuestra carpeta de esp-idf,
o ejecutando comando python. Entrar en terminal "pip install adafruit-ampy", "pip install esptool".
Para ejecutar código en esp entrar en la carpeta del proyecto en terminal, ejecutar python o esp-idf. Comando para la placa:
ampy -p "port_del_esp" run "nombre_del_fichero.py"
